# 内容复刻方法论

把一篇爆款「拆成模板 → 填入自己产品」的通用方法。核心原则：**风格像素级复刻，内容事实原创**。

## 复刻四步

### 1. 提炼可填充模板
从 `target-analysis.md` 中提取**骨架**，把具体内容抽象成槽位：

- 标题 → `[钩子类型] + [核心对象] + [利益/悬念]`
- 每一段 → `[段落作用] + [内容类型]`（如：痛点段 / 方案段 / 体验段）
- 配图位 → `[第N段后] + [图的内容类型]`（截图 / 示意图 / 对比图 / 封面）

关键：保留目标的**结构、节奏、语气**，这些是「像素级」的本体；配图复刻的是**角色与节奏**（何时配图、配什么类型的图），数量按硬约束收敛（见第 4 步）。

### 2. 槽位填充原则
- 产品的**事实**（功能、数据、卖点）只能来自 `product-brief.md`。
- 用户的 `description`（若有）优先级最高：指定了卖点就围绕它选段，指定了语气就覆盖默认语气。
- 目标原文的**具体文字不能照搬**——抄的是套路，不是内容。

### 3. 语气校准
逐项对照 target-analysis 的「语气与人称」「句长节奏」「口头禅」清单：
- 目标用第一人称 + 口语化 → 复刻文也用。
- 目标有标志性口头禅（如「说白了」）→ 换成同功能的表达或沿用通用词，避免明显撞车。
- 金句密度、长短句交替保持同节奏。

### 4. 配图规划（四段式契约）
正文与配图提示词**必须严格对应**：

1. 正文占位符：`![图N：描述](images/NN-slug.png)`，编号 `01` 起、两位数。
2. **数量硬约束：3–5 张（含封面），上限 5 张**。无论目标配图多少张，成稿一律收敛到这个区间；取舍标准见平台细则。**图1 固定为封面**（`01-cover.png`），尺寸按平台标准比例（公众号封面 1504x640 即 2.35:1；小红书封面及全篇配图 1152x1536 即 3:4）。
3. `images-prompt.md` 每张图固定字段：文件名、是否封面、图型（信息图/氛围图）、用途、尺寸、提示词、负面；顶部须有**全局风格约束块**（统一风格、主色调色值、比例规则），逐图提示词继承全局块。
4. 每条提示词按**图型分两套写法**，中文 **80–150 字**：

   **先给每张配图定性**：
   - **信息图**（流程图 / 对比图 / UI 示意图，读者能从图中读到信息）——优先级最高，每篇至少 1 张；
   - **氛围图**（无字装饰性插图）——只作封面/结尾氛围，每篇 ≤2 张。

   **信息图写法**（仅当所用生图模型支持文字渲染，如 glm-image、GPT Image 系；当前 glm-image 官方支持中文文字渲染，直接可用。不支持文字渲染的模型，或质检发现乱码率高时，该图降级标注「人工制作」跳过生图）：
   - 画面中需要出现的文字用引号逐个列出，如 节点文字："打开网页""总结翻译""存笔记"；
   - 明确要求「文字清晰、正确、无乱码」；
   - 布局用简单几何（横排节点、左右分栏），降低模型排版负担。

   **氛围图写法**：
   - 结构为「关键词短句组」：主体一句（对象+动作+状态）、风格一句、光线一句、色彩一句，各自独立，不写成长散文；
   - 删除「主体占画面约六成」类构图百分比（扩散模型执行不了）；hex 色值只保留 1 主色 + 1 点缀色；
   - 风格优先「摄影感、景深虚化、真实材质」路线；**慎用纯扁平插画**（几何透视一旦画歪立刻露馅）；
   - 避免抽象概念描述（如「抽象墨迹暗示段落」），换成具体可画的实物。

   **通用**：每张图附独立「负面」字段（生图时拼接到提示词尾部）：文字、字母、数字、水印、Logo、畸形手部、人脸。信息图的负面去掉「文字、字母、数字」三项（画面需要文字），其余保留。

   新旧提示词对比示例：
   - ❌ 旧式（200 字散文，模型抓不住重点）：画面主体是一叠厚重的纸质长文档，正沿一条蓝紫色传送带被送入一台扁平插画风格的分拣机器，机器出口处吐出三样东西……构图与视角：三分法横向构图……主体占画面约七成……
   - ✅ 新式（关键词短句组）：深夜阅读流水线场景。一叠厚纸质文档沿蓝紫色传送带进入分拣机器，出口输出整齐的要点卡片与节点连线流程图卡片。摄影感数字插画，3D 渲染质感，景深虚化。顶部柔和冷光，出口处蓝紫辉光。深蓝主色，暖橙点缀。干净留白，专业商业插画质感。负面: 文字、字母、数字、水印、Logo、畸形手部、人脸

## 硬约束（不可妥协）
- **不编造事实**：产品数据拿不准用 `[待核实]`，绝不瞎编。
- **风格像、内容新**：复刻对象是套路不是原文，成稿与原文重合的具体表述应为零。
- **占位符与提示词一一对应**：文件名、编号严格一致。
- 全程中文输出。

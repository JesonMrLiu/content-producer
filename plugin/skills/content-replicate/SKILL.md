# 内容复刻方法论

把一篇爆款「拆成模板 → 填入自己产品」的通用方法。核心原则：**风格像素级复刻，内容事实原创**。

## 复刻四步

### 1. 提炼可填充模板
从 `target-analysis.md` 中提取**骨架**，把具体内容抽象成槽位：

- 标题 → `[钩子类型] + [核心对象] + [利益/悬念]`
- 每一段 → `[段落作用] + [内容类型]`（如：痛点段 / 方案段 / 体验段）
- 配图位 → `[第N段后] + [图的内容类型]`（截图 / 示意图 / 对比图 / 封面）

关键：保留目标的**结构、节奏、语气**，这些是「像素级」的本体；配图仅作**参考**：借鉴目标的配图角色与节奏（何时配图、配什么类型的图），**不要求与目标配图画面一致**，最终配图基于本文内容 + 六要素基准自主设计，数量按硬约束收敛（见第 4 步）。

### 2. 槽位填充原则
- 产品的**事实**（功能、数据、卖点）只能来自 `product-brief.md`。
- 用户的 `description`（若有）优先级最高：指定了卖点就围绕它选段，指定了语气就覆盖默认语气。
- 目标原文的**具体文字不能照搬**——抄的是套路，不是内容。

### 3. 语气校准
逐项对照 target-analysis 的「语气与人称」「句长节奏」「口头禅」清单：
- 目标用第一人称 + 口语化 → 复刻文也用。
- 目标有标志性口头禅（如「说白了」）→ 换成同功能的表达或沿用通用词，避免明显撞车。
- 金句密度、长短句交替保持同节奏。

### 4. 配图规划（四段式契约）
正文与配图提示词**必须严格对应**。**配图设计原则：目标配图仅作参考**——配图节奏与角色参考 target-analysis 拆解，每张配图的具体内容与提示词基于本文内容 + 六要素基准自主设计，不模仿目标配图的具体画面：

1. 正文占位符：`![图N：描述](images/NN-slug.png)`，编号 `01` 起、两位数。
2. **数量硬约束：3–5 张（含封面），上限 5 张**。无论目标配图多少张，成稿一律收敛到这个区间；取舍标准见平台细则。**图1 固定为封面**（`01-cover.png`），尺寸按平台标准比例（公众号封面 1504x640 即 2.35:1；小红书封面及全篇配图 1152x1536 即 3:4）。
3. `images-prompt.md` 每张图固定字段：文件名、是否封面、图型（信息图/氛围图）、用途、尺寸、提示词、负面；顶部须有**全局风格约束块**（统一风格、主色调色名描述、比例规则），逐图提示词继承全局块。
4. 每条提示词为**六要素结构化长描述**（写法标准、官方示例与逐例拆解见 `references/prompt-quality.md`，**动笔前必读**），中文 **150–300 字**，信息图画面文字条目多时可到 400 字：

   **先给每张配图定性**：
   - **信息图**（流程图 / 对比图 / UI 示意图，读者能从图中读到信息）——优先级最高，每篇至少 1 张；
   - **氛围图**（无字装饰性插图）——只作封面/结尾氛围，每篇 ≤2 张。

   **六要素**（信息图六项必备；氛围图省略第 5 项画面文字）：
   1. **风格锚点开头**：具体风格/介质词定调（手工剪贴簿 / 复古拼贴 / 哈苏胶片 / 3D 渲染 / 商业海报），不写「高质量、精美」等空词；
   2. **主体具体到单品/部件**：数量、颜色、位置、状态（如「浅蓝宽松毛衣 + 黄格衬衫内搭 + 酒红半裙」级别）；
   3. **空间分区描述构图**：顶部/左侧/右侧/底部逐区交代内容；禁用「主体占画面约六成」类构图百分比（模型执行不了）；
   4. **材质 + 光线 + 色彩**：真实材质词密集（撕裂纸边、和纸胶带、胶片噪点、面料垂坠、毛发细腻）；光线技法具体（轮廓光、高明暗对比、低调柔和人像光、泛光晕染）；色彩用名称 + 色调关系（如低饱和深蓝暗调 + 暖橙点缀），**不写 hex 色值**，保持 1 主色 + 1–2 点缀色；
   5. **画面文字逐字引号 + 字体风格**（信息图核心）：每段文字用引号原样列出并描述字体形态（粗黑体手工剪报风 / 大号白色无衬线 / 手写风标注），收尾要求「文字清晰、正确、无乱码」；
   6. **装饰元素 + 氛围情绪收尾**：小装饰点缀（手绘箭头、星星、放射线、回形针、小图标）；结尾 1–2 个情绪词定氛围（神秘高级 / 诗意梦幻 / 活泼温暖）。

   **风格与抽象约束**：风格不限（剪贴簿 / 拼贴 / 摄影 / 海报均可），但必须有具体材质细节支撑质感，无材质词的纯扁平色块成品必塑料感；避免抽象概念描述（如「抽象墨迹暗示段落」），换成具体可画的实物。

   **信息图补充**（仅当所用生图模型支持文字渲染，如 glm-image、GPT Image 系；当前 glm-image 官方支持中文文字渲染，直接可用。不支持文字渲染的模型，或质检发现乱码率高时，该图降级标注「人工制作」跳过生图）：
   - 节点布局仍宜简单几何（横排节点、左右分栏）降低排版负担，但版面装饰与材质按六要素写足。

   **通用**：每张图附独立「负面」字段（生图时拼接到提示词尾部）：文字、字母、数字、水印、Logo、畸形手部、人脸。信息图的负面去掉「文字、字母、数字」三项（画面需要文字）；人物特写类氛围图（如人像）可再去掉「人脸」项，其余场景保留防畸形。

   新旧提示词对比示例（同一主题「深夜阅读流水线」）：
   - ❌ 旧式（关键词短句组，无材质无分区，成品塑料感）：深夜阅读流水线场景。一叠厚纸质文档沿蓝紫色传送带进入分拣机器，出口输出整齐的要点卡片与流程图卡片。摄影感数字插画，3D 渲染质感，景深虚化。顶部柔和冷光，出口处蓝紫辉光。深蓝主色，暖橙点缀。干净留白，专业商业插画质感。
   - ✅ 新式（六要素结构化长描述）：深夜书房场景的概念插画，复古工业拼贴风格。画面中央是一台写实金属质感的传送带机器，磨损的黄铜边框反射暖光，一叠厚重的米白色纸质长文档躺在深蓝色橡胶传送带上缓缓送入；机器右侧出口整齐吐出三张边缘裁切利落的要点卡片，卡片纸面带细微纤维纹理，用深灰粗黑体分别印着「提炼要点」「生成摘要」「存入笔记」，文字清晰、正确、无乱码。背景上半部分是深灰蓝色调的书房剪影与散落的书页碎片，手绘箭头、星星与做旧回形针点缀其间；底部一条做旧撕裂边缘的牛皮纸色纸带横贯画面，用半透明和纸胶带斜角固定。顶部一盏暖黄台灯向传送带打下柔和聚光，机器出口处泛出蓝紫辉光；整体低饱和深蓝暗调配暖橙点缀，材质细腻，安静专注的深夜工作氛围。

## 硬约束（不可妥协）
- **不编造事实**：产品数据拿不准用 `[待核实]`，绝不瞎编。
- **风格像、内容新**：复刻对象是套路不是原文，成稿与原文重合的具体表述应为零。
- **占位符与提示词一一对应**：文件名、编号严格一致。
- 全程中文输出。

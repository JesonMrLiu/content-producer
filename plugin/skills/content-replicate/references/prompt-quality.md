# 配图提示词质量指南（glm-image 官方标杆）

写每一条配图提示词前必读。glm-image 是自回归 + 扩散混合架构，**擅长理解长指令、渲染中文文字**——提示词要写成结构化场景长描述（官方示例均为 200–400 字流畅中文），不是关键词堆砌，也不是无重点的散文。

## 六要素公式

每条提示词按以下结构组织（顺序可微调，要素不可缺）：

### 1. 风格锚点开头
第一句用一个**具体风格/介质词**定调整张图。不写「高质量、精美、大气」这类空词。
- 官例：「竖版手工剪贴簿风格的图像」「哈苏胶片质感的画面中」「冬季 OOTD 穿搭封面，复古拼贴风」「暗黑艺术感巴宝莉品牌宣传海报」
- 可用流派：手工剪贴簿 / 复古拼贴 / 胶片摄影（哈苏、富士）/ 3D 渲染 / 商业海报 / 水彩手绘 / 杂志版式 等

### 2. 主体具体到单品/部件
主体描述落到**可画的最小单元**：数量、颜色、左右位置、状态。
- ❌「一位女生的穿搭」→ ✅「浅蓝宽松毛衣 + 黄格衬衫内搭 + 酒红半裙 + 粉白花纹围巾 + 粉调手提包」
- ❌「两匹马」→ ✅「两匹写实细腻质感的马（左侧纯白、右侧纯黑），头部均被红黑格纹丝巾蒙住双眼，丝巾呈现自然垂坠的面料纹理」

### 3. 空间分区描述构图
用**方位分区**逐区交代内容：顶部 / 左侧 / 右侧 / 底部 / 前景 / 背景 / 边缘。不写「主体占画面约六成」类百分比（模型执行不了）。
- 官例：「顶部是一条亮红色粗糙撕裂边缘的纸质横幅…左侧有一个带磨损金属边的数码相框…右侧散落三张不同颜色的撕裂纸条便利贴…底部是一整条深蓝色撕裂纸带」

### 4. 材质 + 光线 + 色彩三件套
- **材质**：密集使用真实质感词——粗糙撕裂纸边、半透明和纸胶带、磨损金属边、胶片高噪点、面料垂坠、毛发细腻、水彩晕染、卡纸纹理。这是「高级感」的真正来源。
- **光线**：具体技法——轮廓光、高曝光与高明暗对比、低调柔和人像光、柔和冷光、泛光与晕染、斑驳树影。
- **色彩**：用**色彩名称 + 色调关系**（低饱和深灰暗调、黑白 + 红黑格纹含白与浅棕线条、柔和温暖、深蓝主色暖橙点缀）。**不写 hex 色值**。保持 1 主色 + 1–2 点缀色的克制。

### 5. 画面文字逐字引号 + 字体风格
画面中要出现的每段文字**用引号逐个原样列出**，并描述字体形态与颜色，最后要求清晰正确。
- 官例：「主标题『GLM-Image 开源：国产芯片炼出图像生成 SOTA』，用粗黑体手工剪报风」「大号白色无衬线字体标注『BURBERRY』」「大尺寸浅蓝艺术字『OOTD』，手写风标注文字『autumn/win』『work/date』」
- 收尾一句：「文字清晰、正确、无乱码」

### 6. 装饰元素 + 氛围情绪收尾
- **装饰**：小元素点缀设计感——马克笔放射线、手绘箭头、星星、波浪线、金色回形针、咖啡杯/播放键小图标。
- **氛围**：结尾 1–2 个情绪词 + 整体效果定调——「神秘且契合品牌经典元素」「凝固在午后微风与光影交错的诗意瞬间」「营造活泼的冬日穿搭参考感」。

## 官方四例（按插件图型归类）

### 例 A · 信息图/封面标杆 —— 手工剪贴簿科普插图

> 竖版手工剪贴簿风格的图像。顶部是一条亮红色粗糙撕裂边缘的纸质横幅，用半透明和纸胶带斜着固定，左上角夹着金色回形针，压着一小块写有「首发」的碎纸。横幅上用粗黑体手工剪报风写着主标题「GLM-Image 开源：国产芯片炼出图像生成 SOTA」，标题周围用黑色马克笔画着放射线和手绘画笔调色盘图标。背景是拼贴的AI生成图片碎片、芯片电路图纹理、水彩晕染和浅蓝色卡纸。左侧有一个带磨损金属边的数码相框，用透明胶带斜贴，相框内大字写着「自回归 + 扩散解码器」，副标题「9B 自回归理解指令 + 7B DiT 精绘细节」，背景是文字prompt气泡到精美图像的箭头连接图，边缘有手绘箭头标注「读懂指令」「写对文字」。右侧散落三张不同颜色的撕裂纸条便利贴，被和纸胶带交叉固定。配有芯片实物照片剪影加华为logo小贴纸、中文艺术字海报截图、多分辨率图像网格等插图。三个撕裂纸条标签带粗黑描边：「昇腾 A2 + 昇思 MindSpore：全程国产训练」「CVTG-2K & LongText-Bench：文字渲染开源第一」「384×384 到 2048×2048：任意比例原生支持」。旁边还有一条窄蓝色撕裂纸条写着「认知型生成：知识 + 推理新范式」，上面有马克笔波浪线和星星。底部是一整条深蓝色撕裂纸带，印着电路纹理，用和纸胶带固定。通栏大标题「从"画个图"到"懂您想要什么"的认知型生成引擎」

**要点**：风格锚点 + 顶/左/右/底四区各有明确内容；8 组画面文字全部引号逐字 + 字体风格；材质词密集（撕裂边、和纸胶带、回形针、磨损金属边、卡纸）；装饰（放射线、箭头、星星、波浪线）。

### 例 B · 氛围图（摄影系）标杆 —— 哈苏胶片人像

> 哈苏胶片质感的画面中，一位长发美女置身于柔和的室内光影里，窗外的枝叶在微风中摇曳，将斑驳的树影投射到她的脸庞和肩头；薄纱轻轻垂落在背景，营造出朦胧唯美的氛围，轮廓光勾勒出她慵懒自然的姿态，凌乱的长发在风中轻轻飘起，发丝在阳光的照射下泛着微光；近景特写捕捉她深情凝望镜头的瞬间，清透细腻的肌肤在高曝光与高明暗的对比中展现丰富的质感，背景略微模糊，泛光与晕染交织出轻柔的梦幻效果，画面带有高噪点的胶片色彩与微妙的反射，整体细节生动，仿佛凝固在午后微风与光影交错的诗意瞬间。

**要点**：介质锚点（哈苏胶片）决定全图色彩颗粒感；光线是主角（轮廓光、高明暗对比、泛光晕染、斑驳树影）；材质落到发丝、肌肤、薄纱；机位景深明确（近景特写、背景虚化）；情绪词收尾（诗意瞬间）。全文无一处空泛形容词。

### 例 C · 封面（拼贴系）标杆 —— 冬季 OOTD 社交图文

> 冬季 OOTD 穿搭封面，复古拼贴风：主体是一位女生的主穿搭（浅蓝宽松毛衣 + 黄格衬衫内搭 + 酒红半裙 + 粉白花纹围巾 + 粉调手提包），周围拼贴 2-3 张同系列冬季搭配小图（如蓝羽绒服 + 黑阔腿裤、棕外套 + 藏青裤）；背景融合浅灰方格墙面 + 户外街景局部；添加大尺寸浅蓝艺术字 "OOTD"，手写风标注文字（如 "autumn/win""work/date"），点缀星星、手绘箭头等小装饰，以及咖啡杯、播放键小图标；整体色调柔和温暖，元素错落排版，营造活泼的冬日穿搭参考感

**要点**：用途+风格双锚点开头；穿搭具体到 5 个单品级；「主图 + 周围小图」的层级分区；中英文字混排逐字列出；装饰图标具体（咖啡杯、播放键）；色调与氛围收尾。

### 例 D · 品牌/商业风标杆 —— 暗黑艺术感海报

> 暗黑艺术感巴宝莉品牌宣传海报：整体采用低饱和深灰色暗调背景，配色以黑白（两匹马）+ 巴宝莉标志性红黑格纹（含白、浅棕线条）为主，文字与 logo 为白色；主体是两匹写实细腻质感的马（左侧纯白、右侧纯黑），头部均被巴宝莉经典红黑格纹丝巾蒙住双眼，丝巾呈现自然垂坠的面料纹理；画面右上角放置白色巴宝莉骑士品牌 logo，底部以大号白色无衬线字体标注 "BURBERRY"；光线为低调柔和的人像光，突出马匹毛发的细腻质感与丝巾的格纹细节，整体风格是高级艺术感的时尚品牌风，氛围神秘且契合品牌经典元素

**要点**：先定配色方案（低饱和深灰 + 黑白 + 格纹 + 白字）再摆主体；主体带位置（左白右黑）与状态（蒙眼、垂坠）；版面位置明确（右上角 logo、底部大字）；光线服务材质（人像光突出毛发与格纹）；「神秘高级」氛围收尾。

## 反面模式清单（出现即重写）

| ❌ 反面 | 为什么 | 改成 |
|---|---|---|
| 高质量、精美、大气、超清、4K | 空词，模型无从执行 | 具体风格锚点 + 材质细节 |
| 主体占画面约六成 / 三分法构图 | 模型执行不了百分比 | 顶部/左侧/右侧/底部分区描述 |
| 深蓝 #1E2A4A → #5B6CFF | hex 值对生图无意义 | 低饱和深蓝暗调 + 暖橙点缀 |
| 抽象墨迹暗示段落 / 科技感十足 | 抽象概念画不出来 | 换成具体可画实物 |
| 关键词逗号堆砌、不成句 | 丢失要素间关系与权重 | 流畅中文长句，六要素成文 |
| 无材质词的纯扁平色块插画 | 缺质感参照，成品塑料感 | 任何风格都补材质细节（纸纹/噪点/织物/金属） |

## 长度与自检

- 中文 **150–300 字**；信息图画面文字条目多时可到 400 字。
- 写完自检六问：有没有风格锚点句？主体是否落到单品/部件？是否分区交代了构图？材质/光线/色彩各至少一处？画面文字是否逐字引号 + 字体风格？有没有情绪词收尾？

# 公众号复刻细则

在通用复刻方法论之上，公众号平台的补充规则。

## 篇幅与结构
- 长文体裁：跟随目标的篇幅量级（一般 1500–5000 字）。
- 结构骨架以 target-analysis 拆解为准：常见「导语钩子 → 分节正文（1/2/3/4）→ 结尾互动」或「痛点→解决→体验」三段式。
- 小节分隔方式复刻目标（单独一行数字 `1` `2` `3`，或小标题，或分割线）。

## 标题
- 公众号标题 ≤ 64 字，建议 15–30 字内抓人。
- 复刻目标的钩子类型（疑问 / 数字 / 反差 / 痛点 / 利益）。

## 正文排版
- 段落短：单段 2–4 行，移动端阅读友好。
- 重点句可加粗；加粗密度复刻目标（目标少则少）。
- emoji：公众号通常克制，跟随目标的使用频率。

## 配图
- **数量硬约束：3–5 张（含封面），上限 5 张**——无论目标文章配图多少张，成稿一律收敛到这个区间。复刻的是目标的配图**角色与节奏**（何时配图、配什么类型的图），不是配图数量。
- **封面（图1，`01-cover.png`）最关键：决定打开率。**
  - 比例：**2.35:1**（公众号头条封面标准），生成尺寸 **1504x640**。
  - 构图：关键视觉元素居中、上下留缓冲——信息流与转发卡片会自动裁剪，边缘内容会被切掉。
- 正文插图：**1792x1024** 横版。
- 超出 5 张时的取舍：优先保留承担关键叙事功能的图（痛点共鸣图 / 方案示意图 / 成果对比图）；装饰性细长条、重复氛围图、GIF 位舍弃或合并。
- 图注：一句话呼应上文论点，不复述正文。

## 结尾互动
- 复刻目标的结尾动作（关注引导 / 在看引导 / 评论提问）。
- 公众号名 / 作者未指定时用 `[公众号名]` 占位。

## 平台红线
- 不编造 Star 数、用户量等数据；不盗用他人图片（全部配图用生成图）。

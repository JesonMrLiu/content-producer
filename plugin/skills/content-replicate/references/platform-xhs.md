# 小红书复刻细则

在通用复刻方法论之上，小红书平台的补充规则。

## 篇幅与结构
- 笔记正文 ≤ 1000 字（平台硬限制），一般 300–800 字。
- 结构：开头 1–2 行钩子（决定展开率）→ 分点正文 → 结尾话题标签。

## 标题
- ≤ 20 字（超出会截断）。
- 复刻目标的钩子类型；数字、emoji、紧迫感是常用武器。

## 正文排版
- **emoji 密集**：每行或每点前带 emoji，跟随目标的用法。
- 分点用 emoji 符号（✅🔥💡⚠️ 等）或「1️⃣2️⃣」编号，不用 markdown 列表语法（小红书不渲染 markdown）。
- 纯文本 + emoji + 换行，**不用** `#` 标题、`**` 加粗等 markdown 语法。

## 话题标签
- 结尾带 3–8 个 `#话题` 标签，复刻目标的标签选择思路（品类词 + 场景词 + 热词）。

## 配图
- **图文相互独立（小红书硬规则）**：正文与配图是两个独立部分——正文填在文本框，配图单独上传为图片组。正文中的 `![图N…]` 占位符与图注仅是复刻流程的**中间态标注**（用于图文对应校验与人工审核），最终发布稿不含任何图片占位符、图注、图片路径（剔除在 publish 打包环节完成）。
- **正文不写指涉配图的文字**：发布后图文独立呈现，正文不得出现「如图」「见图2」「上图所示」类引用，正文须独立成篇。
- **数量硬约束：3–5 张（含首图封面），上限 5 张**——无论目标笔记配图多少张，成稿一律收敛到这个区间。目标的配图仅作**参考**（借鉴角色与节奏：何时配图、配什么类型的图），画面内容基于本篇内容 + 六要素基准自主设计，不模仿目标配图。
- **首图 = 封面，决定点击率**：大字报 / 对比图 / 成品图是主流，跟随目标首图类型。
- **比例：全篇统一 3:4 竖版，生成尺寸一律 1152x1536**。小红书整篇笔记只支持一种图片比例（由封面决定），混用横图 / 方图会被系统裁剪，**封面和所有内页图都必须用同一尺寸**。
- 超出 5 张时的取舍：优先保留承担关键叙事功能的图（痛点共鸣图 / 步骤示意图 / 成果对比图）；重复氛围图舍弃或合并。
- 小红书图上常有文字（大字报风格）——glm-image 官方支持中文文字渲染，**直接生成带中文文字的完整图**：提示词按信息图写法把大字报文字逐字引号列出并写明字体风格（粗黑体大字报风 / 手写标注风 / 大号无衬线），收尾要求「文字清晰、正确、无乱码」；画面文字条目控制在 3–5 组以内，降低排版负担。
- **乱码降级**：质检发现文字乱码且重试无效时，才降级为「无文字底图 + 文字后期手动叠加」（在 images-prompt.md 的用途里注明「底图，文字后期叠加」）；降级版底图要给标题文字**预留视觉重心区**（如画面上 1/3 留干净色块）。

## 语气
- 小红书更口语、更「姐妹感」/分享感，跟随目标的语气基线。
- 第一人称体验分享体是主流。

## 平台红线
- 不编造使用效果与数据；不盗图（全部配图用生成图）。
